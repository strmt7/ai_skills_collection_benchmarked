This experimental adaptation derives from Trail of Bits'
[ask-questions-if-underspecified](https://github.com/trailofbits/skills/blob/e8cc5baf9329ccb491bfa200e82eacbac83b1ead/plugins/ask-questions-if-underspecified/skills/ask-questions-if-underspecified/SKILL.md)

CC-BY-SA-4.0. The upstream license is included in `LICENSE`.

The adaptation narrows the original's broad pause and repeated-confirmation
rules. It distinguishes unresolved decisions from authorization, preserves
independent work while required answers are pending, and permits evidence-based
defaults for ordinary reversible choices. The catalog-locked Git bytes of the
original entrypoint are retained in `provenance/original-SKILL.md`; the source
mirror remains unchanged.

The [research note](../../../../docs/research-clarification-decisions.md)
records the source comparison and limits. This adaptation has not been tested
in an independent agent trial and does not establish a performance improvement.
