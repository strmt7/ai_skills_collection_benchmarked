# Attribution and scope

This experimental adaptation addresses one issue in the
[GitHub Actions generator](https://github.com/akin-ozer/cc-devops-skills/blob/7fe7595e4512f8ce43dcf956aa5190b96d627dd1/devops-skills-plugin/skills/github-actions-generator/SKILL.md)
by Akin Ozer, licensed under Apache-2.0. The pinned upstream license is in
`LICENSE`. The source skill and its reusable workflow template are retained in
`provenance/`; the catalog mirror is unchanged.

The new example distinguishes reusable-workflow input types from manual
dispatch input types. It does not replace or qualify the remaining upstream
templates, validators, or operating assumptions. The
[component review](../../../../docs/research-workflow-call-inputs.md) records
the tested cases and their limits. No agent trial has established a performance
improvement.
