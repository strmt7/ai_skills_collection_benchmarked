# Scope and source

This experimental guide addresses the same task as OpenDirectory's pinned
[`claude-md-generator`](../../../skills/by-category/coding-refactoring-repository-automation/reddit-verified-gtm-registry/claude-md-generator/SKILL.md).
It uses the official Claude Code documentation and the current agent instead of
requiring the source's hardcoded external model. The original mirror remains
the catalog baseline. The source package's README declares MIT, but its pinned
tree does not contain a license file at the repository, package, skills, or
skill root; this observation is not a legal determination.

The [research note](../../../../docs/research-claude-md-generator.md) records
the source identities, documentation capture and limits. No independent agent
trial or performance improvement has been established.
