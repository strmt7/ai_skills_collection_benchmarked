# Create slides

Use the request's topic, audience and requested slide count to plan the deck.
Read `html-template.md`, `layout-patterns.md` and the relevant strategy and
copywriting references in this directory. Adapt their examples to the actual
content and cite the source of any externally supplied data.

Create the requested HTML slides in the user's project. Use the maintained
navigation template, provide meaningful slide content and accessible labels,
and keep controls usable by keyboard and pointer. Localize its English navigation
and slide labels. The template loads Chart.js
4.6.1 from a CDN; omit it for a deck without charts or supply an appropriate
local copy when network access is unavailable.

Verify the deck in the intended browser and viewport, including keyboard,
pointer, interactive content, chart rendering and any requested export. Check
text visibility, layout and focus, and report what was not tested.
