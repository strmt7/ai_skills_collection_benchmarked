# Shell generator validation and interpreter selection

The pinned [bash-script-generator skill](../included/skills/by-category/devops-cloud-operations/latest-release-devops/bash-script-generator/SKILL.md) asks for POSIX `sh` when portability is requested, while its standard scaffold contains Bash-specific constructs. [ShellCheck SC3010](https://www.shellcheck.net/wiki/SC3010) documents that `[[ ... ]]` is undefined in POSIX `sh`. In a local control, the source-locked scaffold passed Bash syntax checking but failed syntax checking with `dash`.

The skill also presents its bundled `run_ci_checks.sh` as a fallback after generating a script. That command discovers shell files in the skill's own directories; it does not take the output script as an input. In a separate local control, its bundled syntax checks passed with `--skip-shellcheck --skip-regression-tests` while an independently created output script failed `bash -n`. This establishes the scope of that check, not that every generated script is faulty or that the full skill test suite passed.

The pinned Bash guide describes `set -e` as exiting immediately on a failing command. In the [error-handling control](../artifacts/repaired-skill-readiness/bash-generator-v1/errexit-control.py), a standalone function stops after `false`, but the same function continues when called as an `if` condition. [ShellCheck SC2310](https://www.shellcheck.net/wiki/SC2310) documents this exception and notes that its corresponding diagnostic is optional. The guide's `pipefail` description can also be read as referring to completion time: in the local control, the delayed left command returned 7, the right command returned 4, and the pipeline status was 4. The control describes one installed Bash version, not every shell or execution context.

The [maintained overlay](../included/repaired/skills/by-category/devops-cloud-operations/latest-release-devops/bash-script-generator/SKILL.md) requires checks against the actual output, distinguishes Bash from the requested `sh` target, and calls for behavioral tests. The original mirror remains unchanged. The [component control](../artifacts/repaired-skill-readiness/bash-generator-v1/control.py) is reproducible with explicitly supplied Bash and dash executables; it is not an agent benchmark or proof that a shell script is portable. The GNU Bash manual page requested during this review timed out and was not used as evidence.
