# Use the collection

Find a skill for your task, check its requirements and evidence, then load it in
your agent. This collection is experimental; catalog inclusion alone does not
establish that a skill improves your agent.

| Your goal | Start here |
| --- | --- |
| Set up a local copy and load a skill | [Installation and use](installation.md) |
| Browse by category | [Catalog](catalog/index.md) |
| Start with a compact agent entrypoint | [Agent-ready skills](../included/agent-ready/README.md) |
| Inspect original source and provenance | [Source mirrors](../included/skills/README.md) |
| Understand measured results | [Benchmark results](benchmark-results.md) and [measurement guide](coverage.md) |
| Check requirements for your agent | [Mandatory agent tools](agent-tools.md) |
| Assess release readiness | [Release readiness](improvement-plan.md) |

For API and backend work, see the
[selected component evidence](research-backend-contracts.md). For frontend work,
see [the corresponding evidence](research-frontend-contracts.md). Both explain
their tested boundaries and remaining limits.

For native memory testing and fuzzing dictionaries, see the
[qualified LLVM contracts and experimental overlays](research-native-testing-contracts.md).

For research posters, see the [maintained PDF preflight repair](poster-preflight-repair.md).

For citation management, see the [URL-classification security overlay](citation-security-overlay.md).

To improve this collection, use the separate
[contributor guide](../CONTRIBUTING.md) and
[development setup](development.md). Research records, test harnesses and source
locks support review and reproduction; they are not prerequisites for browsing
the catalog.
