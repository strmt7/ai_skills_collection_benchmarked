# PPT Master SVG editor repair

The [PPT Master repair](../included/repaired/skills/by-category/documents-spreadsheets-presentations/latest-release-creative/ppt-master/SKILL.md) prepares a separate copy of the locked v6.6.0 skill with corrected text movement in its SVG editor. The original mirror is unchanged.

The preparation command verifies the complete source tree, rejects an existing destination, and retains the original skill and attribution. Use the new copy for the presentation workflow. Preparation copies about 13,000 files and can take several minutes. It does not modify an existing installation.

[Component controls](../benchmarks/component-controls/ppt-svg-editor/README.md) describe the tested keyboard, drag, geometry, rollback and asynchronous selection behavior. These controls do not establish whole-skill readiness or an agent benchmark advantage. The original mirror's scanner findings remain open.
