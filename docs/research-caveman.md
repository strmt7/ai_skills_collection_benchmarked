# Caveman: current instructions and evaluation contracts

The stable [3.1.0 release](https://github.com/JuliusBrussee/caveman/releases/tag/v3.1.0)
resolves to `8af1f1b9b1346bca0722a1556f119b4e6675cc96`. GitHub's fresh release
list and peeled tag agree. The previous 3.0.0 checkout remains preserved.
The three style skills, evaluation README, generator, measurement script,
snapshot validator, mode-design document and complete Apache-2.0 license were
read at that pin. The published output matrix was structurally validated;
its answer contents have not received a complete independent fidelity review.

The new default voice favors short, readable prose. Stronger compression and
Classical Chinese are separate explicit modes. It preserves negations, numbers,
units and technical payloads, permits full prose when order or meaning is
ambiguous, exempts persisted material and gives host status requirements
precedence. These are instruction changes, not measured coding improvements.
The applicable internal-only concise style is used during this research.
No hooks, proxy, installers, stored-mode writes or additional AI sessions were
activated. This repository's single-session rule remains binding.

All four catalog Caveman adaptations were read, including their five total
resources. Their pinned versions and repository-specific activation policies
differ. Older upstream wording claims large token savings, encourages dropping
hedging, and permits more aggressive abbreviations. Those claims and choices
cannot override uncertainty, exact commands, authorization or this repository's
progress requirements. Mirrors remain immutable; their older versions and
limitations remain visible.

## Executed controls

[Thirteen isolated snapshot-contract controls](../artifacts/research/2026-10-07/caveman-310-snapshot-contract-controls.json)
execute the actual pinned validator with fixed synthetic inputs and the
published ten-prompt, five-arm matrix. Unequal arm counts, missing controls,
boolean prompt counts and nonstring outputs are rejected. This corrects the
earlier measurement path's possible silent `zip` truncation.

The shape contract still accepts empty/whitespace answers, empty control
answers and an `unknown` model name. Its JSON reader accepts duplicate keys
using the last value. These observations identify limits of the evidence
contract; a structural pass does not establish fidelity, successful generation
or a resolved backend identity. No new model calls were made. The first local
probe used the wrong worker entrypoint name and failed before candidate
execution; it is not an upstream failure or a counted control pass.

The generator now explicitly isolates host settings, MCP and installed skills
in an empty temporary directory. Its source still runs arm blocks serially,
uses one attempt per prompt, records a requested model name rather than a
resolved snapshot, and records output text without complete provider usage.
The measurement uses an approximate tokenizer. Current upstream documents
these cost, fidelity and statistical limits. Its published length reductions
must not be presented as GPT-6.1 Sol results or imported as collection scores.

## Read-only owner quality controls

After the recorded two-hour gate, the scanner's current context-routing guide
and its M25 decision were inspected read-only. They distinguish small initial
route packets from full task context and distinguish measured characters from
API tokens or bills. Concision applies to internal updates; code, persisted
prose, findings, commands, authorization and qualifications retain their full
meaning. No scanner or OMERO file was changed.

Further evaluation must compare default, plain-concise and current Caveman
conditions using independently defined tasks, complete failures and provider
usage, exact source/model identities, and retention of required facts and
ordered actions. Current repository instructions prohibit separate AI sessions,
so independent agent trials remain unavailable under that operating contract.
No category or skill is marked efficacy-complete by these controls.
