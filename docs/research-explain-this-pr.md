# Pull-request explanation scope

The pinned `explain-this-pr` skill says to inspect only the first 200 lines when a diff exceeds 400 lines. A [synthetic control](../artifacts/repaired-skill-readiness/explain-pr-diff-v1/control.py) creates a 513-line diff with a behavioral change in a later file: that change and its filename are absent from the first 200 lines. The retained [Windows](../artifacts/repaired-skill-readiness/explain-pr-diff-v1/windows-result.json) and [Linux](../artifacts/repaired-skill-readiness/explain-pr-diff-v1/linux-result.json) observations identify the same [complete diff](../artifacts/repaired-skill-readiness/explain-pr-diff-v1/raw/full.diff). This establishes a limitation of the excerpt, not the behavior of an AI agent.

The [maintained overlay](../included/repaired/skills/by-category/coding-refactoring-repository-automation/reddit-verified-gtm-registry/explain-this-pr/SKILL.md) calls for inspecting material changes in sections, naming any unreviewed scope, and posting only when explicitly requested. [GitHub CLI documentation](https://cli.github.com/manual/gh_pr_diff) describes the diff command; [GitHub's REST documentation](https://docs.github.com/en/rest/pulls/pulls#list-pull-requests-files) states that the paginated changed-files endpoint returns at most 3,000 files. The control does not exercise GitHub, pagination, posting or a model.

The catalog's canonical mirrored skill and README are preserved in the overlay's provenance directory. The pinned upstream skill has two trailing blank lines beyond the canonical mirror; the README is byte-identical. The README declares MIT, but the pinned upstream tree contains no full license for this skill or the project root. The [source record](../artifacts/repaired-skill-readiness/explain-pr-diff-v1/sources.json) describes these limits and records the documentation capture digests.

To reproduce the local control, run `python artifacts/repaired-skill-readiness/explain-pr-diff-v1/control.py --workspace <new-directory> --output <new-json-file>` with Git installed. The output must be outside the new workspace. This is a component check, not a benchmark of agent effectiveness.
